# Start here

Use a trusted computer with the complete offline kit and an original letter from each participating trustee. Set up and test prerequisites while package repositories are reachable. Disconnect from the network for recovery.

| Computer | Start the local service |
| --- | --- |
| Windows 10/11 | Extract the whole kit to a local drive. Open `start-html.bat`. First use may require installing WSL and Ubuntu, a reboot, and creating a Linux account. |
| macOS | Open `start-html.command` in Finder or run `bash start-html.sh` in Terminal. First use may install Homebrew and packages. |
| Debian / Ubuntu | Run `bash start-html.sh` in the offline directory. The launcher checks Python and `ssss`. |

Leave the terminal open. If the browser does not open, enter the displayed local address on the same computer. Choose **English** or **Deutsch**, then the access category. Enter the entire first share. The form shows how many distinct letters are required. After recovery, click **Reveal for this session**. The result clears after 60 seconds. Use **Clear**, close the browser and press Ctrl+C in the launcher when finished.

For the terminal-only method, run `python3 recover.py`. [Trustee guide](GUIDE.md)
