# Hier anfangen

Ihr braucht den gesamten Offline-Ordner auf einem vertrauenswürdigen Rechner und die Originalbriefe der beteiligten Personen. Richtet die Voraussetzungen vorab mit erreichbaren Paketquellen ein. Trennt den Rechner für die Wiederherstellung vom Netz.

| Rechner | Lokalen Dienst starten |
| --- | --- |
| Windows 10/11 | Den ganzen Ordner auf ein lokales Laufwerk entpacken. `start-html.bat` öffnen. Beim ersten Start können WSL, Ubuntu, ein Neustart und ein Linux-Benutzerkonto erforderlich sein. |
| macOS | Im Finder `start-html.command` öffnen oder im Terminal `bash start-html.sh` ausführen. Beim ersten Start können Homebrew und Pakete installiert werden. |
| Debian / Ubuntu | Im Offline-Ordner `bash start-html.sh` ausführen. Der Starter prüft Python und `ssss`. |

Lasst das Terminal geöffnet. Falls kein Browser startet, öffnet die angezeigte lokale Adresse auf diesem Rechner. Wählt **Deutsch** oder **English**, danach den Bereich. Gebt einen vollständigen Teil ein. Das Formular zeigt euch die benötigte Anzahl verschiedener Briefe. Nach der Wiederherstellung auf **Jetzt anzeigen** klicken. Nach 60 Sekunden wird das Ergebnis geleert. Zum Abschluss **Leeren** wählen, Browser schließen und im Starter Strg+C drücken.

Ohne Browser könnt ihr im Terminal `python3 recover.py` aufrufen. [Bedienungsanleitung](BEDIENUNGSANLEITUNG.md)
